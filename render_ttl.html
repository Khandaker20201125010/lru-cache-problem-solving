DEMO 2: Bonus Feature — Time-To-Live (TTL) Expiration & Lazy Eviction
Creating cache: ttlCache = Cache(3)
[TTL Step 1] Inserting entries with and without expiration:
• cache.put("session_token", "xyz-789", 600) → TTL set to 600ms
• cache.put("api_config", "https://api.internal/v1") → Persistent (No TTL)
[TTL Step 2] Immediate access before expiration:
• cache.get("session_token") → "xyz-789" (Status: Active / Cache Hit)
• cache.get("api_config")    → "https://api.internal/v1" (Status: Active / Cache Hit)
⏳ [TTL Step 3] Waiting 800ms for "session_token" to exceed TTL threshold... (Elapsed > 600ms)
[TTL Step 4] Accessing entries after expiration:
• cache.get("session_token") → -1 (Result: -1 — Expired & Lazy Pruned in O(1) time!)
• cache.get("api_config")    → "https://api.internal/v1" (Result: Value preserved — No TTL)
✔ TTL expiration verified successfully! Clean lazy-eviction on access ensures constant O(1) runtime.
